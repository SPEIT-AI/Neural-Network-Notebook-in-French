# Neural-Network-Notebook-in-French

配套神经网络课程使用的练习题，帮助大家实现“人工”神经网络：-）。由于整套练习题需要使用Python实现，因此第0个练习用于帮助大家了解基础Python代码。希望大家学习愉快！
Ces exercices accompagnent le cours sur les réseaux de neurones et vous aideront à implémenter vos propres réseaux de neurones artificiels :-). Comme l'ensemble des exercices nécessite Python, l'exercice de Td-Tp 0 est conçu pour vous familiariser avec les bases du code Python. Bon apprentissage !
